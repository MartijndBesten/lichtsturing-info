Premium Server Kits

LiveLink Premium Server Kit 5

Standaardpakket van TRILUX voor LiveLink Premium op basis van de Premium Server; aantal Ethernet/DALI Gateways in dit pakket: 6.

Hoort bij
LiveLink Premium
TOC
7540900

In 30 seconden

De Premium Server Kit 5 is een standaardpakket van TRILUX voor LiveLink Premium, op basis van de LiveLink Premium Server, met 6 Ethernet/DALI Gateways. Een van de vijf Server Kits; kies je liever een eigen opbouw, dan combineer je de losse Server met losse gateways.

Hoe werkt het?

De 6 gateways leveren samen 12 DALI-lijnen.

Aansluitklaar pakket. Volgens de System Manual bevat de Premium Server Kit 5:

  • 1 × LiveLink Premium Server
  • 1 × Switch 8-Port
  • 1 × Power Supply Server (voeding van de Server)
  • 6 × Ethernet/DALI Gateway
  • In de kast van Server Kit 5 ook: wandcontactdoos, twee installatieautomaten en een naar buiten gevoerde Ethernet-aansluiting.
