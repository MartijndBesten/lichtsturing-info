IntuSens DALI-2 Input Device

IntuSens-uitvoering die als DALI-2 sensor (Input Device) signalen levert aan een bovenliggende besturing, zoals LiveLink Premium.

Hoort bij
LiveLink Premium

In 30 seconden

Deze uitvoering van IntuSens werkt als DALI-2 sensor (Input Device): hij levert zijn signalen aan een bovenliggende DALI-2-besturing, zoals LiveLink Premium.

Rol in het systeem: DALI-2 sensor (Input Device) — Levert zijn signalen aan een bovenliggende DALI-2-besturing, zoals LiveLink.

Waarvoor gebruik je het?

Oplossingen waarin het wordt gebruikt:

  • LiveLink Premium met DALI-2 sensoren (Input Device) — Bedrade DALI-2 sensoren (Input Device) in LiveLink Premium: de functies stel je centraal in.

Waar zit het in het systeem?

  • Als Sensor op de DALI-lijn in het schema DALI in één schema
  • Als Sensor op de DALI-lijn in het schema Zo is LiveLink Premium opgebouwd: bedraad en draadloos
  • Als Sensor op de DALI-lijn in het schema Zo werkt LiveLink WiFi: wifi voor je telefoon, DALI voor het licht

Hoe sluit je het aan?

IntuSens DALI-2 Input Device in de praktijk:

  • Geen eigen 230 V: de sensor wordt gevoed via de DALI-bus.
  • Busstroom: reken met 6 mA als richtwaarde voor de planning; maximaal 10 mA.
  • De sensor meldt beweging of aanwezigheid en het gemeten licht aan een DALI-2-besturing, zoals LiveLink. Instellen en koppelen gebeurt in die besturing.

Hoe werkt het?

DALI-2 sensor (Input Device)

„Input Device” is de DALI-2-rol van een sensor: hij meet bijvoorbeeld aanwezigheid en licht en geeft die informatie via de DALI-lijn aan de regeling.

De regeling erboven, zoals LiveLink: die beslist wat er gebeurt en stuurt de armaturen aan. De sensor stuurt de armaturen niet zelf aan.

In LiveLink ONE: je wijst de functies van de sensor toe aan armaturengroepen.

LiveLink Premium: de sensor zit op een DALI-lijn van het systeem en wordt via die lijn gevoed.

Productfamilie: IntuSens

IntuSens heeft vier uitvoeringen, één per systeemrol:

  • IntuSens Switch — schakelt de aangesloten armaturen zelf.
  • IntuSens DALI-2 Broadcast — stuurt via DALI alle aangesloten armaturen samen.
  • IntuSens DALI-2 Input Device — levert signalen aan een bovenliggende DALI-2-besturing, zoals LiveLink Premium.
  • IntuSens Bluetooth NLC — draadloos volgens Bluetooth NLC.
