Je kunt in een architectuurschema een ontbrekende verbinding herkennen en de onderdelen aanwijzen die de DALI-lijnen leveren.

Controller of Server en iedere gateway krijgen een eigen aansluiting op de centrale switch; LiveLink Premium-componenten worden niet onderling doorgelust via hun Ethernet-poorten. Schema-oefening · Basis

Welke verbinding ontbreekt?

Een installateur stuurt een schets van een Premium Server-installatie over twee verdiepingen. Gateway 2 wordt bij het in bedrijf stellen niet gevonden.

1 Welke verbinding ontbreekt in deze tekening?

  • Ethernet van de switch naar gateway 2
  • Ethernet van gateway 1 naar gateway 2
  • DALI van de LiveLink Premium Server naar gateway 2

Bekijk uitleg
  • Ethernet van de switch naar gateway 2 logische keuzeIedere gateway krijgt een eigen aansluiting op de centrale switch. Zonder die verbinding kan de LiveLink Premium Server gateway 2 niet bereiken.
  • Ethernet van gateway 1 naar gateway 2 Dat is doorlussen: LiveLink Premium-componenten worden niet onderling via hun Ethernet-poorten doorgelust.
  • DALI van de LiveLink Premium Server naar gateway 2 De LiveLink Premium Server praat via Ethernet met de gateways; DALI begint pas bij de gateway.

Uit de kennisbank

Controller of Server en iedere gateway krijgen een eigen aansluiting op de centrale switch; LiveLink Premium-componenten worden niet onderling doorgelust via hun Ethernet-poorten. Dat is een TRILUX NL-ontwerpuitgangspunt: de officiële documentatie beschrijft de opbouw via een switch en spreekt zich over doorlussen niet uit.

  • Een netwerkpoort voor de centrale unit en voor iedere gateway, plus eventuele koppeling tussen switches.
  • Afstemming met IT over het netwerk, zeker bij grotere projecten.

2 Tik in het schema de onderdelen aan die de DALI-lijnen leveren.

Tik in het schema de onderdelen of verbindingen aan en kies daarna Controleer.

Bekijk uitleg

De Ethernet/DALI Gateways: zij zetten de opdrachten van de LiveLink Premium Server om naar DALI. De LiveLink Premium Server zelf heeft bij deze opbouw geen DALI-lijn.

Uit de kennisbank

Voor grotere systemen: tot 2.000 DALI-apparaten. Alle DALI-lijnen komen via Ethernet/DALI Gateways.

Welke informatie ontbreekt nog om definitief te ontwerpen?
  • Of de switch genoeg poorten heeft voor alle gateways.
  • Wie het netwerk levert en de IP-afspraken maakt.
Voor de trainer

Laat eerst iemand hardop het schema ‘lezen’ van boven naar beneden. De ontbrekende lijn valt dan vaak vanzelf op.
