2 Waarom is dat een probleem?

  • Premium-componenten worden niet onderling doorgelust; iedere gateway hoort op de centrale switch
  • Omdat er dan DALI over Ethernet loopt
  • Het maakt niet uit hoe je Ethernet aansluit

Bekijk uitleg
  • Premium-componenten worden niet onderling doorgelust; iedere gateway hoort op de centrale switch logische keuze
    Dat is de ontwerpregel; zo blijft iedere gateway onafhankelijk bereikbaar.
  • Omdat er dan DALI over Ethernet loopt
    Nee: over deze verbinding gaat Ethernet; DALI loopt alleen tussen gateway en installatie.
  • Het maakt niet uit hoe je Ethernet aansluit
    Wel: de ontwerpregel is een eigen aansluiting per component op de centrale switch.
