DALI zonder LiveLink

Voor: alle doelgroepen

Handig om eerst te kennen: Wat zit er op één DALI-lijn?

Na dit onderdeel

Je kunt uitleggen dat DALI het protocol is en LiveLink één manier om er een lichtregelsysteem mee te bouwen, en welke rollen een zelfstandige DALI-regeling nodig heeft.

Protocolnorm

DALI is het protocol; LiveLink is één manier om er een compleet lichtregelsysteem mee te bouwen. Een eenvoudige, zelfstandige DALI-regeling heeft nodig:

  • netvoeding voor de armaturen en voor andere componenten die netvoeding nodig hebben;
  • een busvoeding, en één DALI-bus;
  • control gear: de DALI-drivers in de armaturen;
  • een application controller die beslist wat er gebeurt;
  • eventueel input devices, zoals een sensor of een drukknopinterface.

Protocolnorm

Drie rollen op een DALI-bus:

RolVraagVoorbeelden
Input deviceWat gebeurt er?aanwezigheid, lichtwaarde, een druk op een knop
Application controllerWat moeten we ermee doen?regels en logica; bepaalt de opdracht
Control gearVoert de lichtopdracht uitdimniveau, scène, aan of uit

Protocolnorm

Eén product mag meerdere rollen combineren. Een sensorproduct kan bijvoorbeeld input device én application controller zijn. In de installatie lijkt het dan alsof de sensor het armatuur rechtstreeks aanstuurt. Technisch gebeurt er dit: het input device in het product meldt een gebeurtenis, de application controller in hetzelfde product beslist, en die stuurt een DALI-opdracht over de bus naar de drivers.

Protocolnorm

Een busvoeding is geen besturing. Ze houdt de bus onder spanning zodat er gecommuniceerd kan worden, maar beslist niets. Wat de verlichting doet, bepaalt de application controller. Een busvoeding kan een los product zijn of ingebouwd in een besturing of driver.

Controlevraag

Een ruimte heeft een busvoeding, DALI-drivers en een sensor met ingebouwde application controller op één DALI-bus. Is LiveLink nodig om het licht op aanwezigheid te regelen?

  • Nee: de application controller in de sensor beslist en stuurt de drivers aan. LiveLink is één manier om een groter systeem te bouwen.
  • Ja: zonder LiveLink kan een DALI-sensor niets.
  • Nee: de busvoeding regelt het licht.

Bekijk het antwoord

Het juiste antwoord: Nee: de application controller in de sensor beslist en stuurt de drivers aan. LiveLink is één manier om een groter systeem te bouwen.

Voor de trainer

Vraag eerst: „Kan DALI zonder LiveLink?” Laat het schema stap voor stap zien en wijs bij de laatste stap aan wie beslist. Benadruk: de busvoeding is geen controller, en een sensor die het licht „rechtstreeks” lijkt te schakelen, heeft een application controller aan boord.
